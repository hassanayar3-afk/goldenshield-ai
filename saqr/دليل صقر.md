- **اللغة:** Rust (workspace: `saqr-core` + `saqr-cli`)

## 7. التشغيل

```bash
cd saqr
cp .env.example .env   # إن لم يكن .env موجوداً
# عدّل .env — Binance + Telegram + CLOUD_SERVER_* + SAQR_PUBLIC_DASHBOARD_URL

cargo build --release
cargo run --release --bin saqr
```

- **لوحة التحكم:** http://127.0.0.1:8787 (أو `SAQR_WEB_BIND_PORT`)
- **API:** `/api/health`, `/api/status`

---

## 8. ملف `.env` (لربط السحابة وTelegram وBinance)

افتح **`/home/ubuntu/saqr/.env`** (موجود محلياً، **غير مرفوع** إلى GitHub) وعبّئ:

| متغير | الغرض |
|--------|--------|
| `BINANCE_API_KEY` / `BINANCE_API_SECRET` | مفاتيح المنصة |
| `BINANCE_REST_URL` / `BINANCE_WS_URL` | روابط API (testnet/live) |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | التنبيهات |
| `TELEGRAM_SECONDARY_BOT_TOKEN` | مسار احتياطي anti-flood |
| `CLOUD_SERVER_HOST` / `PORT` / `SSH_USER` | السيرفر السحابي |
| `SAQR_PUBLIC_DASHBOARD_URL` | رابط صفحتك العامة للربط |
