# قناة GoldenShield Vault — أرشيف النسخ الاحتياطية

البوت **لا يستطيع إنشاء قناة عبر الـ API**. أنت تنشئ القناة مرة واحدة بالتصميم أدناه، ثم تربطها بالمشروع.

## تصميم القناة (انسخه كما هو)

| الحقل | القيمة المقترحة |
|--------|------------------|
| **الاسم** | `النسخ الاحتياطي` |
| **اليوزرنيم** (اختياري) | اختياري — يُفضَّل بدون يوزرنيم (خاصة) |
| **الوصف** | أرشيف نسخ قاعدة بيانات GoldenShield AI — خاص |
| **صورة الغلاف** | أي أيقونة درع/محفظة |
| **النوع** | قناة خاصة (Private) |
| **التعليقات** | معطّلة |
| **من يمكنه الكتابة** | المشرفون فقط (`@GoldenShield_2026_bot` مشرف) |

رسالة التثبيت المقترحة (يثبّتها البوت بعد الربط عبر السكربت):

```
🛡️ GoldenShield Vault
━━━━━━━━━━━━━━━
أرشيف النسخ الاحتياطية الرسمي

• نسخ يومية من قاعدة SQLite
• استرجاع بعد انقطاع أو جهاز جديد
• لا تشارك رابط هذه القناة
```

## الخيار الأسهل: محادثتك الشخصية

بدون إنشاء قناة — النسخ تصل إلى دردشتك مع `@GoldenShield_2026_bot`:

```env
TELEGRAM_BACKUP_CHANNEL_ID=<نفس TELEGRAM_CHAT_ID>
```

أو:

```powershell
.\.venv\Scripts\python.exe scripts\setup_telegram_backup_channel.py --personal
```

## خطوات ربط قناة منفصلة (اختياري)

1. في تيليجرام: **New Channel** → اسم `GoldenShield Vault` → **Private**.
2. **Administrators** → أضف `@GoldenShield_2026_bot` بصلاحية **Post Messages**.
3. انشر رسالة تجريبية لمعرفة الـ ID (`-100xxxxxxxxxx`).
4. ضعه في `.env` أو استخدم `--channel-id` / `--discover`.

## ماذا يُحفظ؟

- ملف `.db` يومي من `storage/db/backups/`
- تعليق HTML: البيئة، الوضع، الحجم، الوقت، خطوات الاستعادة

Google Drive يبقى اختيارياً؛ **القناة هي المسار الافتراضي السهل**.

## الاستعادة لاحقاً

1. حمّل أحدث ملف من القناة.
2. شغّل:

```powershell
.\.venv\Scripts\python.exe scripts\restore_backup.py مسار\الملف.db
```

أو يدوياً: أوقف البوت → انسخ الملف إلى `storage/db/goldenshield.db` → شغّل البوت.

## رفع فوري بدون انتظار منتصف الليل

```powershell
.\.venv\Scripts\python.exe scripts\send_backup_now.py
```
