# التحديث التلقائي بين الحاسوب وGitHub والهاتف

## الفكرة ببساطة
```
حاسوبك  ←→  GitHub  ←→  وكيل الهاتف
```

- إذا عدّلت شيئاً على الحاسوب → يُرفع تلقائياً إلى GitHub  
- إذا عدّل وكيل الهاتف ورفع إلى GitHub → الحاسوب يسحب التعديل تلقائياً  
- أنا على الحاسوب أرى نفس الملفات بعد السحب التلقائي

## ما تم تفعيله
- سكربت: `scripts/git_autosync.ps1`
- مهمة ويندوز: `GoldenShieldGitAutoSync`
- كل **15 دقيقة**: سحب ثم رفع (بدون ملف `.env`)
